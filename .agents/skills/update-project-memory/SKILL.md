# Update Project Memory

Read the existing memory, relevant sources, decisions, task contract, validation evidence, and human approval before editing.

Separate:

- Facts completed
- New decisions
- Unresolved issues
- Next step

Update only the memory files authorized by the task. Never invent completion, silently resolve ambiguity, or promote a recommendation to a decision. Never overwrite historical decisions; add a new decision that explicitly supersedes an earlier one when authorized. Keep `CURRENT_STATE.md`, sprint evidence, `CHANGELOG.md`, and `DECISION_LOG.md` consistent with their distinct purposes.
