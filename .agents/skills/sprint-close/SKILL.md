# Sprint Close

Read the sprint scope, current project memory, decisions, test records, deliverables, and required human validation.

Check and report:

- Scope status for every committed item
- Required test and QA evidence
- Unresolved blockers and deferred work
- Decisions created or still required
- Documentation and project-memory consistency
- Human validation where required

Return **READY TO CLOSE**, **NOT READY**, or **BLOCKED**, with evidence and explicit remaining actions. Do not mark the sprint complete, edit status files, move work, or create a release unless separately authorized. Blocking items prevent automatic closure.
