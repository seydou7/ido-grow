# Task Specification

Read the mandatory project memory and relevant sprint/domain files. Resolve only facts available from authoritative sources; label missing decisions and blockers instead of guessing.

Produce a contract containing:

- Objective
- Context
- Files and references to read
- In-scope behavior
- Out-of-scope behavior
- Owner
- Reviewers
- Acceptance criteria
- Tests required
- Files that must not be modified
- Completion report format

Make acceptance criteria observable. Ensure the named owner and reviewers follow the repository Builder → Reviewer → QA agreement. Do not implement the task while creating its specification unless implementation is separately authorized.
