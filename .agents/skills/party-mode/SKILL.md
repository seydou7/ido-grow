# Party Mode

Use Party Mode only when explicitly requested.

## Workflow

1. Awa owns orchestration.
2. Read the mandatory project memory and relevant current sprint files before delegating.
3. Define the decision or investigation boundary and choose the smallest useful specialist set; do not summon all 13 agents by default.
4. Delegate bounded, independent questions. Prefer parallel read-heavy analysis and avoid parallel write-heavy editing.
5. Wait for every selected specialist and distinguish evidence from assumptions and recommendations.
6. Present:
   - Facts
   - Assumptions
   - Specialist perspectives
   - Agreements
   - Disagreements
   - Risks
   - Recommended decision
   - Whether a `DECISION_LOG.md` update is required
   - Next action
7. Do not implement the recommendation unless the user explicitly requests implementation afterward.
