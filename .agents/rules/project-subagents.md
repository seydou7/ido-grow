# Project Agent Subagent Invocation Rule

When a task assigns responsibility to an I Do Grow Project Agent, the parent must delegate that responsibility through a genuine Antigravity Custom Subagent invocation when available.

Reading `.agents/agents/<name>.md` into the parent context does NOT count as agent participation.

Do not claim `<Agent> PASS` unless that agent had its own invoked subagent session and returned the verdict.
